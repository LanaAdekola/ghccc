# Post-launch checklist

- Verify both church addresses and headquarters schedule on mobile.
- Confirm branch schedule separately before publication.
- Check Spotify and all restored YouTube/resource links.
- Test anonymous draft/role/submission/storage denial and authenticated editorial workflows.
- Verify real form persistence, rate limiting, spam controls, response process and retention cleanup.
- Confirm giving accounts; enable checkout only after provider/account approval and server verification implementation.
- Validate all metadata, sitemap, redirects, icons and image loads.
- Run mobile Lighthouse; target 90+ in all categories and document exceptions.
- Validate GTM Preview/GA4 DebugView after consent; no sensitive fields, admin activity or duplicate tags.
- Verify Search Console and submit sitemap. Do not promise search-result update timing.
- Record rollback deployment and administrator recovery access.
